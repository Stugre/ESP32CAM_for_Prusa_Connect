# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added
- Wi-Fi network scanning on the setup page.
- Support for storing a blank Wi-Fi password for open networks.
- mDNS hostname support at `http://esp32cam.local`.
- Reboot and factory reset controls on the web page.
- Manual `Test upload now` action with visible result feedback.
- Last upload status panel showing automatic/manual upload result, HTTP status, and bytes sent.
- Info badges beside settings with plain-English value explanations.

### Changed
- Prusa Connect token and fingerprint fields are now masked in the web UI.
- Snapshot and stream buttons use distinct colors from save/upload actions.
- Top action buttons are horizontally aligned.
- Sensor options span the full page width and are arranged in multiple columns.

## [1.0.0] - 2026-05-29

### Added
- GitHub Pages project landing page and workflow support.
- Public project documentation and MIT license.
- A simple project preview graphic for the repository README.

### Updated
- Firmware documentation and release-facing project notes.
- Dependency and source metadata used for the current firmware build.
